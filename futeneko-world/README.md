# フテ猫ワールド — せってい・デザインを変えるときのガイド

公開URL：https://ganapati0330.github.io/futeneko-world/

## セーブはどこにある？
- 遊んでいる人のデータ（持ち物・畑・家・家具・レベル）は、その人のブラウザに保存されています（`futeworld_v1_slot0〜2`）。
- `index.html` を新しい版に差し替えても、このデータは消えません。
- 保存のたびに、ひとつ前のデータも控え（`_bk`）として残します。

## 自由に変えてよいもの（セーブは壊れません）
`index.html` の「せかいの せってい」と書かれたあたりから下の DATA 部分です。

| 変えたいもの | 場所（キーワードで検索） | 遊んでいる人のデータへの影響 |
|---|---|---|
| マップの大きさ | `MW` / `MH` | 畑や植えた物は座標で保存しているので、位置はずれません |
| 道・森・まちの形 | `genMap` の中 | 植えた物が道や建物と重なったら、自動で持ち物に戻します |
| エリア・出てくるモンスター | `ZONES` | なし |
| ボスの場所・強さ | `BOSSES` / `MOB` | なし |
| 建物の場所 | `BLD` | 重なった植物は持ち物に戻ります |
| 自分の土地の範囲 | `LAND` | すでに植えた物はそのまま残ります |
| ねだん・育つ日数 | `ITEMS` / `CROPS` | なし |
| 家の大きさ・増築のねだん | `HOUSES` | 部屋が狭くなったら、置けない家具は持ち物に戻します |
| 家具・壁紙・床 | `FURN` / `WALLS` / `FLOORS` | なし |
| DIYのレシピ | `DIY` | なし |
| 町の人のセリフ | `NPC_TIPS` | なし |

## 気をつけること
1. **アイテム・家具の「ID」を変えるとき**（例：`turnip` → `kabu`）
   `ITEM_ALIASES` または `FURN_ALIASES` に `{'turnip':'kabu'}` と書いてください。持っていた分が新しいIDに引き継がれます。
2. **アイテムや家具を削除したとき**
   持っていた分は隠して保管します。あとで同じIDで戻せば、持ち物に戻ってきます。
3. **変えてはいけないもの**
   - `SKEY`（セーブの名前）
   - `NET.base`（オンラインの世界の名前）。変えると、前の版の人と別の世界になります。
4. **バージョン番号**
   `VERSION` を上げたら、`sw.js` の `CACHE` 名も同じ番号にしてください。上げないと、古い版がキャッシュから表示されることがあります。
5. **セーブの形を大きく変えたとき**
   `SCHEMA` の番号を上げて、`normalizeSave` に移行の処理を追加します。

## 体力と魔法
- HPは、攻撃を受けてから4秒たつと少しずつ自然に回復します（家の中では早く回復）。寝るとHP・MPが全回復します。
- MPは時間とともに回復します。魔法はレベルで覚えます：ファイア(Lv1)・ヒール(Lv3)・アイス(Lv5)・サンダー(Lv8)・トルネード(Lv12)・メテオ(Lv16)。
- 狙いは近くのモンスターに自動で合わせます。紫のボタン（PCはE）で唱え、「⇄」（PCはR）で魔法を切りかえます。
- 魔法の強さ ＝ 3 ＋ レベル×2 ＋ つえ。つえは、かじやで「きのつえ」「ミスリルのつえ」が作れます。
- 魔法の種類や強さは `SPELLS` と `castSpell` で変えられます。

## みんなで同時プレイ（オープンワールド）
- 同じ世界（同じあいことば）にいる人は、モンスターとボスを**共有**します。
- いちばん先にログインしていた人の端末が、モンスターを動かす役（🛡️ホスト）になります。ホストが抜けると、次の人が自動で引き継ぎます。
- 誰の攻撃・魔法も同じモンスターに効きます。倒したときは、攻撃した人**全員**が経験値・お金・落とし物をもらえます。
- ボスの技（弾・予告の円・突進・ジャンプ）は全員に届きます。ボスを倒すと、その日は全員の世界でボスがいなくなります。
- ほかの人の攻撃や魔法も見えます（見た目だけ。ダメージはホストが計算します）。
- 家・畑・持ち物・木や岩は、これまでどおり一人ずつのものです。

## オンライン・チャット
- 「🌐」ボタン：いっしょに遊んでいる人の一覧、ミュート、あいことばの設定、チャットのON/OFFができます。
- **あいことば**：同じあいことばを入れた人だけの世界になります（家族だけで遊びたいときにおすすめ）。
- チャットの安全対策：悪い言葉は伏せ字になります。電話番号・メールアドレス・URLは送れません。40文字まで、2秒に1回まで送れます。困った相手はミュートできます。
- 悪い言葉を増やしたいときは `NG_WORDS` に追加してください。
- 通信には、無料で誰でも使える公開中継サーバーを使っています。中身は暗号化されていないので、大事なことは書かないでください。

## ログインなまえ と サーバーの名簿
- キャラを作るとき、サーバーの名簿を見て、同じ名前がもう登録されていたら使えません（全角・半角・大文字・小文字は同じ名前として扱います）。
- 名前・キャラ・レベル・登録日・最後にログインした時間を、中継サーバーの「保持メッセージ」（retained）として世界ごとに保存します（`<世界>/reg/<プレイヤーID>`）。
- 「🌐」の画面の「サーバーの なかま名簿」で、登録している人全員（ログインしていない人も）を見られます。
- 名前はメニュー →「なまえをかえる」で変えられます（名簿も変わります）。セーブを消すと、名簿からも消えます。
- 注意：無料の公開サーバーなので、名簿がずっと残る保証はありません。あいことばの世界ごとに名簿は別です。

## パスワード
- メニュー →「🔑 パスワード」で、名前にパスワード（4〜16文字）を付けられます。
- 付けると：
  - タイトルでそのセーブを開くとき、パスワードを聞かれます。
  - セーブがパスワードで暗号化（AES-GCM）されてサーバーに預けられます。保存されるのは1分ごと・寝たとき・タイトルに戻るときです。
  - 別の端末のタイトル画面から「🔑 なまえと パスワードで ログイン」を選ぶと、そのデータを呼び出せます。
- 名簿に入るのはパスワードそのものではなく、変換した値（ハッシュ）だけです。
- パスワードを忘れると、別の端末からログインできません。おうちの人とメモしておいてください。
- 同じキャラで2台同時にログインすると、あとから保存したほうのデータが残ります。

## うまくいかないとき
- 画面の左下に赤い「エラー: …」が出たら、その文字をClaudeに伝えてください。
- データの引っ越し：メニュー →「データをかきだす」でコードを出し、タイトル画面の「データをよみこむ」に貼り付けます。
