# フテ猫 北奥羽の戦国シミュレーション（青森版）— 引き継ぎ

公開：https://ganapati0330.github.io/aomori-sengoku/（v1.0）
もと：中国地方版 `src/futeneko-sengoku/`（v9.4）を コピーして、地域に しばられた ところだけ 入れかえた もの。

## つくりかた

```
npm install
python3 build.py              # → dist/（index.html・sw.js・img/）。公開時は bgm.mp3・apple-touch-icon.png も そえる
node lint.js                  # 未定義の 変数などの チェック
node test_logic.js など        # test_*.js（ぜんぶ 0 failures）
node csim.js allcpu 12 normal 1571   # CPU どうしの つり合い（1590 も）
node e2e_aomori.js [desk|se]  # Playwright（dist を localhost:8765 で 配信して）
```

## 中国地方版から かえた ところ

| もの | ファイル | 中身 |
|---|---|---|
| 境界データ | `make_geo.py` → `geo.json` / `geo.js` | 国土数値情報（行政区域、niiyz/JapanCityGeoJson 2020 版）を 19 領地に まとめた。弘前市・青森市は 城の 位置の ボロノイで 2つに わけた。八郎潟（大潟村）は 湖に もどした。**元データは 島の 多い 市（むつ・深浦・男鹿・八峰・田野畑・函館など）で 島の 輪郭が「穴」として 入っている ので、輪郭を すべて 陸地として よみなおしている**（`rings2land`）。変数名は 中国地方版の まま `CHUGOKU_GEO` |
| 世界ヘックス地図 | `gen_world.js` → `world.js` | 経度 139.60〜142.10・緯度 39.44〜41.64、212×281 マス。山（岩木山・八甲田・岩手山 など）・峠（来満峠・矢立峠・中山峠・区界峠 など）・川（岩木川・馬淵川・米代川・北上川 など）・湖（十和田湖・小川原湖・十三湖・八郎潟）。`SANIN` は「日本海がわ」の 意味で つかっている（奥羽山脈の 尾根を つくる） |

## 史実の あつかい（説が わかれる ところ）

- 石川高信の 死：津軽がわは 1571年、南部がわは 1581年。ゲームでは 1571年の 夜討ちで 滝本重行に 当主が かわる。
- 斯波氏の 1571年の 当主を 斯波詮真、浅利氏を 浅利勝頼と した（諸説あり）。
- 石川家（津軽郡代）・七戸家・八戸家は、ゲームの つごうで 南部家と 同盟した 別の 家に して いる（じっさいは 南部一族の ゆるい まとまり）。
