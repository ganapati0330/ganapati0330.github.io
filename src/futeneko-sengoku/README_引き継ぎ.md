# フテ猫 戦国シミュレーション — 仕組みと、ほかの地域版を作るための引き継ぎ

公開中の中国地方版：https://ganapati0330.github.io/futeneko-sengoku/（v9.4）
このフォルダ：その元のプログラム一式（`ganapati0330/ganapati0330.github.io` の `src/futeneko-sengoku/`）

## 1. つくり

ビルドすると 1枚の HTML（`dist/index.html`）と `sw.js`・`img/` ができる。

```
python3 build.py        # → dist/ に出力
node lint.js            # 未定義の変数などのチェック
node test_logic.js など  # テスト（test_*.js）
```

| ファイル | 中身 | 地域を かえる とき |
|---|---|---|
| `game.js` | 合戦（ヘックスの 戦闘、ユニット、AI、兵糧、撤退、合流） | ほぼ そのまま |
| `ui.js` | 合戦の 画面・入力・HUD | そのまま |
| `kuni.js` | 国取りの 画面（地図、城の 画面、内政、出陣、家臣、一覧表） | 地名 `GEO_NAMES`・`NEAR_LABELS` を かえる |
| `campaign.js` | 国取りの ルール と データ | **大名家 `CLAN_BASE`・国 `PROVS`・支城 `BRANCHES`・名産 `MEIBUTSU`・シナリオ `SCENARIOS`・武将 `OFFICERS`** を かえる |
| `events.js` | 史実の できごと（家督、厳島…）と 武将の セリフ | 地域の 史実に 書きかえ |
| `geo.js` / `geo.json` / `chugoku.json` | 国の 境界・海岸線（国土数値情報 から 作った 座標） | 新しい 地域の 境界データを 用意 |
| `gen_world.js` → `world.js` | 1km ヘックスの 世界地図（海陸・山・川・道・城の 位置）を 生成 | 経度・緯度の はんい、国 id、城の 位置を かえて 再生成 |
| `lordart.js`・`art/` | 大名の 顔絵 | 新しい 大名の 絵 |
| `spr.js`・`gfx/`・`*.webp` | キャラ・兵・城・アニメの 絵 | 城の 絵・兵の 絵は 流用できる |
| `template.html` | 画面の HTML・CSS・あそびかた | タイトル・説明文 |
| `csim.js` | CPU どうしで 遊ばせる つり合いの テスト | そのまま |

## 2. 地域に しばられて いる ところ（青森版などで 作りなおす もの）

1. **国（りょうち）の 区分け**：`PROVS`（id・名前・旧国・石高・城の 型・ピン位置）、`ADJ`（となり）。中国地方は 旧国を さらに 郡単位で わけて 18 に している（例：安芸 → 佐西・佐東・吉田・大朝・東西条・沼田）。
2. **境界データ**：`geo.json` は 国土数値情報の 行政区域から 作った もの。変換スクリプトは この フォルダに のこって いないので、新しい 地域では 作りなおしが 必要。
3. **世界ヘックス地図**：`gen_world.js` の 先頭に ある 経度・緯度の はんい（`LON0`・`LAT0`・南端・東端）、国 id、国の 名前 `PNAME`、本城の 位置 `PIN`、日本海がわ `SANIN` を かえて `node gen_world.js` で `world.js` を 作る。標高は 実測では なく モデル（尾根・峠・山・川）。
4. **支城**：`BRANCHES`（国ごとに [名前, 経度, 緯度, 城の 型]）。
5. **大名家・シナリオ・武将**：`CLAN_BASE`（名前・色・家紋）、`SCENARIOS`（開始年・大名・はじめの 兵・同盟）、`OFFICERS`（武・政・智、登場年〜去る年、寝返り）。
6. **できごと**：`events.js`。
7. **地名**：`kuni.js` の `GEO_NAMES`（町・山・川・峠）、`NEAR_LABELS`（まわりの 国・海の 名前）。
8. **見た目**：タイトル絵 `menu.webp`、大名の 顔絵。

## 3. いまの おもな ルール（v9.4）

- きせつ ごと（春夏秋冬）に すすむ。本城は 国の めいれい 3つまで（出陣・徴兵・調略）、支城は 城 ごとに きせつ 1かい。内政（田畑・町・鉱山・改築など）は めいれいを つかわず、領地 ぜんぶに お金の かぎり たてられる。
- 家臣は 城に いて、その 城で はたらく。🚶で 城を うつる。
- 出陣：城を えらぶ → 目標 → ほかの 城から 応援 → 大将。兵糧は 城の 蔵から（1人 1日 2.5合）、たりない ぶんだけ お金。
- 合戦：国ざかいから 攻めこみ、本丸に 入れば かち。兵糧ぎれで ひきあげ。援軍・補給（小荷駄）・撤退・合流・とちゅうの セーブ。
- 降参兵・連勝の 志願兵・武将の 寝返り、こわれた 城の 修理、一揆、同盟／中立／敵対、領地の 一覧表。

## 4. 青森版を 作る ときの すすめかた（案）

1. このフォルダを 作業場所に コピーして、ビルドと テストが とおる ことを たしかめる。
2. 時代と シナリオを きめる（例：南部氏・津軽為信の 独立〜九戸政実の 乱 など）。
3. 国（りょうち）の 区分けを きめる（郡・城の 単位：津軽・外ヶ浜・糠部・鹿角 など、はんいは 北奥羽で どこまで 入れるか）。
4. 国土数値情報などから 境界データを 作り、`geo.js` を 作る → `gen_world.js` を 書きかえて `world.js` を 作る。
5. `campaign.js` の データ（大名家・国・支城・武将・シナリオ）を 入れかえ、`events.js` を 書きかえる。
6. 地名・タイトル・あそびかたを 書きかえ、`csim.js` で つり合いを みる。
7. 公開先は 別の フォルダ（例：`ganapati0330.github.io/aomori-sengoku/`）に する。
